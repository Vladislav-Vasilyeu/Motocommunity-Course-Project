# Проверка гаража, публикаций, друзей, сообществ и маркета

Дата: 24 ноября 2026. Проверка задач #65 и #66 выполняется скриптом
`server/scripts/qa/social.mjs` через HTTP API и cookie `motoclub_session`.
Общий HTTP-клиент: `server/scripts/qa/client.mjs`.

## Безопасный запуск

Нужен отдельный локальный API с отдельной временной PostgreSQL, всеми миграциями
и обычной конфигурацией авторизации. Не указывайте API рабочей базы.

```powershell
$env:QA_API_URL='http://localhost:4314'
$env:QA_ALLOW_WRITES='1'
node MotoClub/server/scripts/qa/social.mjs
```

Клиент требует обе переменные и принимает только localhost/loopback. Скрипт создаёт
три независимых аккаунта с UUID в email и уникальный маркер содержимого. Он не
использует демонстрационные учётные записи и не читает секреты. Нет прямого доступа
к БД, повышения ролей или операций над чужими данными. Положительные мутации
проверяются повторным HTTP-чтением; отрицательные проверяют HTTP-статус, а часть
также стабильный код ошибки. Проверки группируют связанные HTTP-утверждения:
47 случаев не означают 47 запросов.

После прогона остаются синтетические аккаунты, два сообщества, дружба, обработанная
заявка и связанные уведомления: API не предоставляет их полного удаления.
Тестовые мотоцикл, публикации и объявление удаляются через API по ходу сценария.
При отказе проверки созданная сущность также может остаться. Удаление временной
базы — ответственность запускающего изолированное окружение координатора.

## Фактический результат

Первый прогон на изолированном `localhost:4314`: 42 PASS, 1 FAIL из 43 случаев.
Дефект: `POST /api/communities/<несуществующий UUID>/join` возвращал 500
`INTERNAL_SERVER_ERROR`. Причина в `server/src/routes/api.ts`: upsert участника
без проверки существования сообщества нарушал внешний ключ и попадал в общий
обработчик ошибок. Исправление production-кода выполнил координатор отдельно.

Повторный расширенный прогон после исправления: **47/47 PASS**, код завершения 0,
включая запрошенную координатором конкурентную проверку вступления.
Итог скрипта: `{"suite":"social","passed":47,"status":"PASS"}`.
`npm --prefix MotoClub/server run build`: успешно, Prisma Client и TypeScript.
Frontend не менялся, его сборка в рамках этой части не запускалась.

## Границы проверки и отсутствующие операции

- Это проверка HTTP-контрактов и сохранения данных через API; браузер, формы,
  клавиатура, адаптивность, RU/EN и темы здесь не проверяются.
- У сообществ реализованы создание, список, просмотр, вступление и выход.
  Редактирование/удаление сообщества и передача владения не реализованы; они не
  заявляются как прошедший CRUD. Сообщение OWNER_CANNOT_LEAVE упоминает передачу
  прав, но соответствующего API нет.
- У дружбы реализованы отправка заявки, accept/decline и список друзей.
  Удаление друга, отзыв исходящей заявки и отдельный список исходящих не реализованы.
- У объявлений нет отдельного GET по id и восстановления CLOSED → ACTIVE через
  текущий PATCH. Закрытые сохранённые объявления остаются в избранном по текущему
  контракту. Для изменения этих правил нужно продуктовое решение.
- Гараж/публикации проверены по всем реализованным CRUD-операциям. Приватный журнал
  обслуживания, диалоги и уведомления относятся к другим QA-наборам.
- Каталоги ограничиваются первыми 50 записями; поиск райдеров — первыми 20.
  Нагрузочные проверки, пагинация и гонки кроме трёх одновременных вступлений
  одного участника не входят в набор.
