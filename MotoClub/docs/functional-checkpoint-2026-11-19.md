## Как повторить проверку API

Используйте отдельную временную базу: сценарий создаёт пользователей и контент. Обычная рабочая база для этого не требуется.

1. Укажите `DATABASE_URL` временной PostgreSQL через переменную процесса, примените `npm --prefix server run db:deploy` и `npm --prefix server run db:generate`.
2. Выполните seed с `$env:SEED_DEMO_MODERATOR='1'`, затем удалите этот флаг. Команда: `npm --prefix server run db:seed`.
3. Соберите и запустите API с этой базой: `npm --prefix server run build`, `npm --prefix server start`. Для отдельного экземпляра задайте свободный `PORT` и нужный `CLIENT_ORIGIN`.
4. В другом PowerShell задайте адрес API и явное разрешение тестовых записей:

   ```powershell
   $env:SMOKE_API_URL='http://localhost:4306'
   $env:SMOKE_ALLOW_WRITES='1'
   node server/scripts/check-functional.mjs
   ```

Обычный запуск приложения описан в корневом README; удалять или сбрасывать рабочую базу не нужно.

## Ограничения и оставшиеся проверки

- Очередь жалоб ограничена последними 100 записями выбранного статуса; полноценная пагинация пока не реализована.
- Настройки темы и языка локальны для браузера, без синхронизации аккаунта между устройствами.
- Русский служит исходным словарём; отсутствие английского ключа показывает исходную подпись. Для новых языков потребуется перевод интерфейса и соответствующие формы множественного числа в `countLabel`.
- Внешний Google Maps SDK выбирает язык при первой загрузке. После смены языка приложение предлагает перезагрузить страницу для перевода встроенных элементов карты. Цветовая схема задаётся по выбранной теме.
- Реальная карта с настроенным ключом ранее отображалась; текущие изолированные проверки выполнены без ключа, со штатным сообщением и доступными списками точек. Полный вход через личный Google-аккаунт с завершением consent/callback ещё не подтверждён.
- Google-интеграция и исправление двух демонстрационных строк из предыдущей незавершённой сессии входят в эту версию. Секреты `.env` не входят в коммит.
- Доступность проверена по структуре полей, фокусу и контрастным токенам; отдельная проверка экранным диктором и на физических мобильных устройствах ещё нужна.
